# Infant Jesus Management System

A full-stack school website and student admission management platform built for **Infant Jesus Academy**. Designed to streamline online student applications, administrative reviews, and academic record management.

🔗 **Live Demo:** https://infant-jesus-academy.vercel.app

---

## ✨ Key Features

* **Online Admission Portal:** Responsive multi-step application form with client- and server-side validation for prospective students.
  
* **Administrative Dashboard:** Secure role-based portal for school administrators to review applications, update admission statuses, and manage student records.

* **Document & Media Uploads:** Integrated cloud storage for student passport photos and admission credentials.

* **Automated Notifications:** *(Include if using Resend/email triggers)* Instant confirmation emails upon application submission and status updates.

* **Real-Time Database & Security:** Powered by PostgreSQL with strict Row Level Security (RLS) policies protecting student and staff data.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router) & TypeScript
  
* **Styling:** Tailwind CSS
  
* **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL, Auth, Storage)

* **Error Monitoring:** Sentry

* **Deployment:** Vercel
